PHASE 02: Backend & Database (Flask, SQLite, Schemas, Seed Data)
--------------------------------------------------------------------------------
- Design normalized 3NF SQLite database schema with PostgreSQL compatibility.
- Implement tables: users, trains, train_schedules, bookings, passengers, sessions,
  behavior_events, behavior_features, risk_assessments, security_actions.
- Implement WAL-mode connection manager (database/db.py).
- Populate database with realistic train schedules, station matrices, and fares.
- Connect SQLite persistence to the Flask booking routes.

PHASE 03: Behavioral Telemetry Collector (telemetry.js & Ingestion API)
--------------------------------------------------------------------------------
- Implement client-side telemetry engine (frontend/static/js/telemetry.js).
- Collect multi-signal behavioral dimensions:
    * Keyboard: Keydown/keyup timestamps, inter-key intervals (dt), typing cadence.
    * Mouse: 2D coordinates, Euclidean distance, velocity, curvature, pause frequency.
    * Scrolling: Scroll events, burst timing, page inspection intervals.
    * Form Interaction: Field dwell times, field-to-field transition latency.
- Enforce strict privacy filters: NEVER capture typed passwords or payment details.
- Implement server-side telemetry receiver (behavior_tracking/collector.py).

PHASE 04: Human Data Collection Workflow & Protocol
--------------------------------------------------------------------------------
- Establish controlled experimental protocol for genuine human booking sessions.
- Document participant guidelines, consent protocol, and anonymized session tagging.
- Collect diverse human baseline interaction sessions across varied devices and typing speeds.
- Store raw session batches in data/raw/human/.

PHASE 05: Controlled Bot Simulator (Selenium Multi-Profile Suite)
--------------------------------------------------------------------------------
- Build controlled Python + Selenium automation framework (bot_simulator/).
- Strictly target localhost (NO interaction with real IRCTC or external portals).
- Implement 5 distinct automation profiles:
    1. BOT_PROFILE_FAST: Zero-delay, instant DOM filling.
    2. BOT_PROFILE_FIXED_DELAY: Deterministic constant delay between actions.
    3. BOT_PROFILE_VARIABLE_DELAY: Randomized uniform/normal delay distributions.
    4. BOT_PROFILE_FAST_FORM: Human browsing speed with instant form filling.
    5. BOT_PROFILE_ALTERNATE_NAVIGATION: Direct URL jumping & skipped workflow steps.
- Execute batch automated runs and store sessions in data/raw/bot/.

PHASE 06: Dataset Processing Pipeline (Clean, Session-Grouped Datasets)
--------------------------------------------------------------------------------
- Build data ingestion and sanitization pipeline (features/pipeline.py).
- Validate telemetry schemas and filter corrupt/incomplete sessions.
- Enforce strict ANTI-LEAKAGE session-level partitioning:
    * All events from session X reside strictly in Train, Validation, or Test.
    * Reserve unseen bot profiles exclusively for test holdout.
- Output clean session tables to data/processed/.

PHASE 07: Feature Engineering & Feature Dictionary Validation
--------------------------------------------------------------------------------
- Convert raw event time-series into 21+ session-level behavioral features:
    * Keystroke: typing_speed_cpm, interkey_mean_ms, interkey_std_ms, interkey_entropy.
    * Mouse: mouse_total_distance, mouse_mean_speed, mouse_speed_std, curvature_ratio.
    * Clicks: click_count, click_interval_mean, click_interval_std.
    * Scroll: scroll_count, scroll_interval_mean.
    * Form/Session: form_completion_time, field_dwell_mean, request_frequency.
- Formalize schema and data dictionary (docs/FEATURE_DICTIONARY.md).

PHASE 08: Machine Learning Baseline & Training Pipeline
--------------------------------------------------------------------------------
- Implement reproducible ML pipeline (ml/training/train.py).
- Train primary model: Random Forest Classifier (Scikit-learn).
- Train scientific baseline models: Logistic Regression and XGBoost.
- Evaluate using GroupKFold cross-validation grouped by session_token.
- Serialize trained models and scaler preprocessors to ml/models/.

PHASE 09: Risk Scoring Engine & Threshold Calibration
--------------------------------------------------------------------------------
- Implement real-time risk scoring engine (risk_engine/scorer.py).
- Map model probability P(Bot | X) to normalized 0-100 Bot Risk Score.
- Calibrate risk thresholds using validation ROC curves:
    * LOW RISK    (0 - 39):  Frictionless booking permitted.
    * MEDIUM RISK (40 - 69): Additional verification challenge required.
    * HIGH RISK   (70 - 100): Dynamic rate-limiting and temporary restriction.
- Target: False Positive Rate (FPR) < 2% on genuine human sessions.

PHASE 10: Explainability & Risk Attribution Module
--------------------------------------------------------------------------------
- Build explainability engine (risk_engine/explainability.py).
- Extract Random Forest tree feature importances and calculate local feature deviations.
- Generate top 3 human-readable contributing risk signals for every flagged session.
- Example output: "Form completion (0.42s) is 95% faster than human baseline".

PHASE 11: Adaptive Security & Graduated Defense Gateway
--------------------------------------------------------------------------------
- Implement graduated defense middleware (security/policy.py).
- Prevent destructive hard IP bans based on single probabilistic inferences.
- Execute adaptive countermeasures:
    * Cognitive verification challenge for borderline sessions.
    * Token-bucket delay queue for suspicious request bursts.
    * Temporary session restriction for the active booking window.
